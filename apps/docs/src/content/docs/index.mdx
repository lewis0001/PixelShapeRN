Welcome to the BOTFORGE documentation.

BOTFORGE is an open, modular robotics platform: palm-sized robots assembled
from standard electronic modules and 3D-printed bodies.

## What lives here

- **Robot guides** — step-by-step build guides for each robot in the catalog.
  These pages are **generated by the BOTFORGE engine** from robot definitions
  and synced into this site; they are not hand-written here.

This site is part of the Phase 0 scaffold. Generated content starts landing in
Phase 1.
