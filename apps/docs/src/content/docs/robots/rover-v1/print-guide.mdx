All of Rover's printed parts are designed to print **without
supports**: no overhang tricks, no rafts, no glue. Any well-tuned FDM printer
with a 0.4 mm nozzle can produce them.

## Settings

Use the `pla-0.20` profile that ships with this robot, or dial in the same
values by hand:

- **Layer height:** 0.2 mm
- **Walls / perimeters:** 3
- **Infill:** 15% gyroid
- **Supports:** none — every part is support-free by design
- Print each part flat on the bed in its default orientation.

all `body` parts one color and all `accent` parts another, and the robot will
look the way it does on the site — but this is your build, so any palette goes.
